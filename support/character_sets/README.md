# Japanese font character sets

`japanese_unicode_ranges.txt` defines the contiguous Unicode blocks used by
the Japanese UI font. Empty or unassigned code points are ignored by the font
converter when the source font has no glyph for them.

`jis_x_0208_level1.txt` contains the 2,965 level-1 kanji from rows 16 through
47 of JIS X 0208. The file is generated by decoding those row/cell positions
with Python's standard `iso2022_jp` codec. Each line corresponds to one JIS
row, in ascending order. Newlines are separators and are not font glyphs.

The generator combines both files, removes duplicate characters while
preserving code-point order, and passes the resulting subset to
`lv_font_conv`.
